# Catarina visual identity

Catarina's interface is a dark, glassy planning workspace. Neon mint is the
brand accent; blue-black surfaces keep boards and drawers calm, while section
colors distinguish work areas. The light theme switches to cool paper blue and
a deeper green accent.

| Role | Color |
| --- | --- |
| Dark background / surface | ![#060B14](https://img.shields.io/badge/-%23060B14?style=flat-square&color=060B14) `#060B14` / `#0D1824` |
| Dark accent | ![#00E8A2](https://img.shields.io/badge/-%2300E8A2?style=flat-square&color=00E8A2) `#00E8A2` |
| Light background | ![#F4F8FF](https://img.shields.io/badge/-%23F4F8FF?style=flat-square&color=F4F8FF) `#F4F8FF` |
| Light accent | ![#008F5A](https://img.shields.io/badge/-%23008F5A?style=flat-square&color=008F5A) `#008F5A` |
| Section accents | coral `#FF4D6A`, violet `#7C3AED`, blue `#3B82F6`, amber `#F59E0B` |
