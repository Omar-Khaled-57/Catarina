Real-Time Sync

Changes from other team members appear within 5 seconds — no page reload needed. Delta fetching means only modified data is transferred. Smart polling adjusts based on tab visibility. Optimistic mutations make your actions feel instant, with automatic rollback if something fails.

💬

Comments & Assignments

Comment on goals to discuss progress. Assign team members with granular permissions — who can check, who can edit. Section members get notified automatically.

🔄

Live Activity Indicators

New goals from other users shimmer with a teal glow. Dashboard section cards pulse when goals change. Toast notifications appear for incoming updates in the navbar.

Polish & UX

Experience
📱

Progressive Web App

Install Catarina on any device — phone, tablet, or desktop. Works offline with a service worker that precaches assets and uses network-first for pages.

♿

Accessibility

ARIA live regions for screen readers, proper checkbox roles, prefers-reduced-motion support, and semantic HTML throughout.

🎉

Update Celebrations

When a new version lands, you get a tiered celebration modal — major, minor, or patch — showing exactly what's new with the in-app changelog.

🎨

Catarina Expressions

The Catarina mascot reacts to what's happening — celebrating completions, thinking during edits, sleeping when idle, and waving hello.

🔒

Security

HttpOnly JWT cookies (XSS-safe), bcrypt password hashing, rate limiting on auth endpoints (10/min per IP), and secure cookie flags in production.

🖼️

Media & Assets

Static assets — stickers, profile pics, and fonts — have infinite browser cache with immutable headers for instant loading.
